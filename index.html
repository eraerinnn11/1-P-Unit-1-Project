The Saxophone

There are four main types of the Saxophone

  • Soprano
  • Alto
  • Tenor
  • Baritone

(in order of size)

About The Saxophone

The saxophone has 22 to 23 keys

Things you need to start playing the Saxophone (any type)

  1. A Saxophone
  2. A mouthpiece*
  3. Reeds!*
  4. A neckstrap

( *- specific to your type of Saxophone )
